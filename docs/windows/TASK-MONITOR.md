# Windows 任务监控

[Windows 使用说明](README.md) · [监控设计](TASK-MONITOR-PROPOSAL.md) · [验证范围](VALIDATION.md)

选择正在执行的 Codex 主任务，在所选轮次结束后获得提示。监控对象与用量统计筛选独立；本工具不向 Codex 发送消息、代为审批或停止任务。

## 开始监控

1. 打开主面板“任务监控 → 选择任务”。
2. 按名称或项目搜索，勾选一个或多个可确认正在执行的任务。
3. 选择“仅本轮”或“每轮”，点击“开启 N 项提醒”。

“仅本轮”绑定选择时的轮次，结束后保留结果。“每轮”持续关注同一任务后续轮次；一轮结束后等待下一轮，不自动加入其他任务。保存时重新核对身份与轮次，不把迟到选择转成下一轮监控。

可以在任务已经执行后加入监控，无需重新发起任务；长任务和刚开始、尚未产生 Token 的任务也可被发现。首次发现需要读取历史日志；尚未恢复可靠开始事件时显示待确认，核对完成后会自动允许选择。创建时间和开始时间的精度不同不影响首次开始事件的识别；旧版因此留下的待确认状态会在启动后重新核对。

## 静默形态下看状态

圆环和侧签用独立小符号表示任务状态，额度弧、百分比和电池填充仍只表示额度。托盘也提供任务摘要。新消息不会自动展开、移动窗口、切换页面或持续闪烁。

| 符号 / 状态 | 含义 |
| --- | --- |
| 三角形：正在执行 | 来源确认该轮仍在执行，不表示完成百分比 |
| 勾：本轮已结束 | 收到明确结束事件，不代表整个需求已完成 |
| 方形：本轮已中断 | 收到明确中断事件，与正常结束区分 |
| 问号：状态待确认 | 来源不可用或无法确认轮次，保留上次记录 |
| 等待新一轮 | 持续订阅有效，当前没有执行中的轮次 |
| 感叹号：等待处理 | 仅在来源可靠支持时使用；当前日志来源不开放此类提醒 |

“常驻关注”决定圆环和侧签重点显示哪个已选任务，不停止其他监控。展开后的动态摘要汇总全部已选监控；未读数单独统计消息，不受单任务关注影响。

## 浮窗快捷操作

展开浮窗并选择“监控”：

- 顶部显示重点状态与未读入口。点击打开消息列表；有未读时筛选未读，没有时显示历史。打开列表不自动标读。
- 每张任务卡可“查看”或“取消监控”。取消只停止本工具订阅和提醒，Codex 继续执行，已有消息保留。
- “清除已结束结果”移除结束的监控结果，保留活动订阅和消息。
- “检查任务”重新检查本地日志，显示进行中、检查时间、部分可用或失败重试。它不检查 Codex 网络，也不测试系统通知。
- “提醒设置”控制呈现方式；更多任务和消息进入主面板查看。

收起、隐藏或关闭主面板均继续监控。退出本工具后停止；重新启动会恢复订阅并核对离线事件。

## 消息、取消与清理

| 操作 | 影响 |
| --- | --- |
| 查看任务详情 | 不自动读完该任务的所有消息 |
| 打开某条消息或标为已读 | 改变对应未读状态，不停止监控 |
| 全部标为已读 | 只改变消息，不清除执行状态 |
| 清理已读历史 | 移除符合条件的已读历史，保留未读及仍需处理的消息 |
| 清除已结束结果 | 移除结束的订阅结果，保留活动订阅和消息 |
| 取消监控 | 停止本工具提醒，保留 Codex 执行和已有消息 |
| 暂停任务通知 | 继续记录和更新标记，暂不发送通知 |

已读与执行状态独立。读过等待提示不代表已处理；结束状态可以作为结果保留。历史保留默认 30 天，可选 7、30、90 或 365 天；未读和有效监控记录不按普通已读历史静默清理。

当前开发源码中，点击单条或批量任务通知均进入“本次通知消息”，只列出该通知关联的消息，不自动标读。“本通知全部标为已读”只处理固定关联范围，新到消息不受影响；“返回全部历史”取消该范围。系统通知还提供“暂停 30 分钟”按钮，无需打开主面板即可暂停任务通知，监控和消息记录继续。

## 提醒方式

默认“系统通知＋应用内标记”，声音关闭；可选择“仅应用内标记”、隐藏任务名称或暂停通知。系统通知包含任务名称和状态摘要，不显示提示词、回复正文或文件内容。

全屏、系统忙碌或暂停期间继续记录，恢复后不逐条补弹旧消息。是否显示由 Windows 及其设置决定；API 提交成功不代表已看到横幅。通知设计提供查看详情和后台标为已读，但真实横幅、通知中心点击与冷启动通知回调尚未完成可靠端到端验收，见[验证范围](VALIDATION.md)。应用内消息可独立查看。

## 能力与限制

当前来源是本机 Codex 日志中的明确开始、结束和中断事件，未接入当前桌面实例的受支持实时状态接口。新启动的独立服务不能替代现有桌面任务的状态来源。

日志不可靠提供等待审批或执行失败事件，这两类提醒保持禁用。对应图形和接口为未来可靠来源保留，不能将设计稿里的状态都理解为当前可用。

日志安静、Token 不增长、断线或子任务结束不能单独判断主任务完成。没有真实百分比或预计结束时间时不展示猜测进度。“本轮结束”不等于代码正确、验证通过或需求全部完成。

任务详情提供名称、项目和标识；当前不承诺直接跳转 Codex 对应任务。

## 数据位置与恢复

订阅、设置、消息和读取检查点保存在 `%LOCALAPPDATA%\CodexUsageDashboard\desktop\task-monitor.json`。`CODEX_USAGE_DESKTOP_BASE` 可覆盖数据目录。本工具不改写 Codex 日志。

重启按任务和轮次去重；离线完成补入记录，不补弹通知。读取失败保留上次记录并标记待确认；存储损坏保留原文件，提供“备份并恢复监控记录”，不修改 Codex 任务。问题报告应删去私人名称、目录和账号信息，不要上传完整监控文件。
