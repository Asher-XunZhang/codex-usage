# macOS v1.0.3

发布日期：2026-09-18。提供 Apple Silicon（arm64）和 Intel（x86_64）独立安装包。Windows 继续使用 v1.0.2，本次未修改 Windows 界面或共享统计后端。

## 变化

- 单窗口弧线调色板：单色、随额度变化的双色渐变、色轮、HEX 输入、预设与恢复内置配色。应用才保存，取消、Escape 和关闭撤销草稿。
- 修复嵌入预览中的百分比偏移、外层窗口阴影受影响以及预览额度整数不一致。
- D「微弧融合」贴边轮廓适配四边；无任务时数字居中，活跃监控或未读消息按需扩展，结束且已读后按活跃状态缩回。
- 可见轮廓与鼠标命中一致，保留连续形变、拖动、键盘、减少动态效果与已有边缘归属规则。

[最新视图与交互图片](FLOATING-1.0.3.md) · [调色板说明](ARC-COLORS.md) · [安装](INSTALL.md)

## 验证范围

- Apple Silicon 本机完整回归，包含原生 AppKit、预算、任务监控、浮窗生命周期与安装器测试；不支持的平台保留跳过项。
- 原生布局检查覆盖深浅主题、四个方向、运行 / 未读 / 无任务、`100%*` 和 `99+`；另验证绘制与命中、任务增减、接缝归属和动画。
- 已安装候选版中操作贴边、拖动、点击展开、键盘展开与手动收起。文档图片使用合成数据离屏渲染，不是用户桌面录屏。
- 两架构分别构建，ZIP 逐文件校验、架构、执行权限、嵌套签名、固定运行组件及 App / source 源码摘要须通过发行验证器。
- 两种架构的宿主与主面板组件均执行独立目录的 `--check-runtime`；Intel 在 Rosetta 下执行，不等于实体 Intel 验收。

未完成实体 Intel、干净设备首次下载信任流程、完整拔屏 / Spaces / 休眠与系统通知冷启动验收。当前为 ad hoc 签名，未进行 Developer ID 签名或 Apple 公证。

## 来源与重建

Release：<https://github.com/Asher-XunZhang/codex-usage/releases/tag/v1.0.3>。同名 tag 固定编译源码提交；包内 `source/` 与 `Contents/Resources/BUILD-INFO.json` 提供源码快照和指纹。构建命令见 [构建文档](BUILDING.md)。

先定稿 ZIP，再单独更新安装助手固定 SHA-256；不会为回写自身摘要重打包。安装本版请使用 Release 独立 `install.sh`，ZIP 内源码的脚本可能仍对应上一发行版。旧版资产与 Windows 包不替换。
