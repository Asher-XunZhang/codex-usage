## 再次复核：收起按钮与圆环重叠

用户进一步指出收起按钮与收起后的圆环重叠时仍无法收起。此前原生 Surface 测试只验证按钮触发了 collapse，没有覆盖窗口形变引起的退出事件。新增停靠控制器反例：手动收起后，先送退出事件、实际鼠标不动，再送进入事件。修复前在“Geometry-generated exit cannot cancel manual-collapse suppression”失败（`overlap-before.log`）。
