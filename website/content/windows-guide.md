# Windows 使用指南

本页对应 **Windows v1.0.3**。首次使用先[完整解压并打开 CodexUsage.exe](./installation.md#windows)。macOS v1.0.3 的操作见[macOS 使用指南](./user-guide.md)。

## 主面板：用量、预算与任务

顶部导航分为「用量概览」「预算管理」「任务监控」。显示方式与设置入口始终可用，切页保留窗口与各页状态。

### 查看本机用量

选择今天、7 天、30 天、90 天或全部时间，再按模型、任务筛选。卡片显示总 Token、输入、输出、缓存输入和模型调用；趋势与明细用于查看时间变化和具体记录。

明细支持按模型或任务分组、搜索、排序与 CSV 导出。**搜索只影响明细表**；导出默认保存当前显示行，也可选择当前范围的全部行。主面板与浮窗的用量筛选各自保存，不会改动预算范围或监控对象。

切换筛选时重新读取该范围。读取失败保留错误与重试入口，不把旧范围的数值当作新结果，也不会导出未确认的数据。

### 本地日志和账号额度分别更新

「刷新」请求本地用量和账号额度，两者各自显示成功时间、状态与错误。「本地自动更新」控制日志扫描，账号额度启用时按独立节奏读取，可在设置中即时关闭或开启；可从「数据更新状态与重试」分别重试。

Token 是已经落盘的本机记账；周剩余等百分比来自账号额度。未知显示「—」，旧快照有状态标记，二者不能按固定比例换算。[统计口径 →](./metrics-and-privacy.md)

## 预算提醒：掌握使用节奏 {#budgets}

进入「预算管理 → 新建预算」，选择需要关注的口径：

| 口径 | 如何使用 |
| --- | --- |
| Token 数量 | 设置周期内限额，可选总 Token、非缓存输入加输出，或仅输出，并按模型、任务限定范围。 |
| 估算金额 | 填写模型每百万 Token 的输入、缓存输入与输出单价；支持 USD，或按手填固定汇率显示 CNY。空价格表示未知，不按零元计算。 |
| 官方余量下限 | 选择实际可用的官方额度窗口，设置剩余百分比下限；使用账号快照，不按本机 Token 推算。 |

周期支持日、周、月、一次性时间范围和固定时长，并保存时区。本周期已经发生的用量会计入新预算，不从保存那一刻重新起算。

保存后可查看本期用量、余量、状态与最近提醒，也可选择在浮窗中查看。暂停提醒会继续统计，停用预算停止该项监测。预算只提醒，不会终止 Codex 任务、阻止请求、改变官方限额或兑换重置卡。

保存区会说明哪些修改立即生效、哪些下期生效，也可明确选择重算本期。未保存草稿按预算保留。缺少价格、额度窗口失效或配置损坏时，使用页面提供的补齐、重新选择或备份恢复入口。

## 任务监控：在本轮结束时提醒 {#monitoring}

1. 打开「任务监控 → 选择任务」，勾选正在执行的主任务，可多选。
2. 默认选择「仅本轮结束后提醒」；需要持续关注同一任务时选择「每轮结束都提醒」。
3. 关闭主面板后继续工作，圆环、侧签和托盘保留所选任务的状态。

监控对象独立于用量筛选。「取消监控」只停止本工具对该任务的提醒，Codex 继续执行，已有消息保留。「清除已结束结果」清理结束的监控项，保留活动监控与消息历史；标为已读只清除未读状态。

### 静默形态也能看见状态

| 标识或状态 | 含义 |
| --- | --- |
| 三角形 · 正在执行 | 所选任务有已确认的执行中轮次 |
| 勾 · 本轮结束 | 已收到主任务本轮结束事件；不代表整个需求已经完成 |
| 方形 · 已中断 | 来源明确记录了中断 |
| 问号 · 状态待确认 | 来源不可用、记录不完整或暂时无法核实，不能当作完成 |
| 独立未读数量 | 尚未读过的任务消息，与执行状态分别记录 |

圆环与贴边侧签同时显示任务状态和未读数字，超过 99 显示 99+；额度弧、电池条和百分比仍表示额度。没有可靠完成百分比时，不显示猜测的进度条。

当前本地日志来源不能可靠提供等待审批与执行失败事件，因此这两类提醒暂不可选，界面会说明原因。不会把日志安静、子任务结束或断线当作主任务完成。

### 选择提醒方式

在「任务提醒设置」选择「系统通知＋应用内标记」或「仅应用内标记」。默认无声，可选择声音、隐藏通知中的任务名称与项目，或暂停任务通知。

点击系统通知可查看本通知关联消息，并仅将这些消息全部标为已读，也可返回全部历史。通知内可暂停任务提醒 30 分钟；预算通知还提供「本周期不再弹出」。任务提醒设置支持保留 7、30、90 或 365 天消息。全屏、游戏、系统忙碌、勿扰或暂停通知期间，状态与消息继续记录；恢复后不逐条补弹历史消息。新消息不会抢走焦点、自动展开浮窗或切换当前内容。

可在设置中发送测试通知并打开 Windows 通知设置。**提交成功不等于横幅已经显示**；没有收到时按[通知排查步骤](./troubleshooting.md#windows-notifications)检查。

## 浮窗：圆环、贴边侧签与展开面板 {#floating}

### 圆环与展开

圆环常驻显示额度和摘要，短暂停留后连续展开为详情面板，离开后收回圆环。展开方向按当前位置的剩余空间选择；靠左向右、靠下向上，尽量让整个面板留在任务栏以外的工作区。

| 内容页 | 顶部与快捷操作 |
| --- | --- |
| 用量 | 电池式周剩余额度与今日 Token，下方查看独立范围的用量明细。 |
| 预算 | 电池式当前预算余量，选择预算并查看其周期、范围与提醒状态。 |
| 监控 | 全部已选任务的动态摘要、独立未读入口；每项可查看详情或取消监控，还可清除已结束结果、检查任务或进入提醒设置。 |

监控页的未读入口打开消息列表，不自动标为已读。任务较多时，通过「查看全部任务与消息」进入主面板。三个内容页共用底部「打开主面板」与「收起」。

### 拖动与贴边隐藏

- 收起时按住圆环拖到任意位置；展开途中也能抓住可见部分继续移动圆环。
- 完全展开后，按钮、文字和空白都能作为左键拖动起点。移动达到拖动距离后只移动窗口，不执行原按钮；未形成拖动时仍正常点击。
- 松手后，越界的展开面板回到可见工作区。下次从圆环展开时重新选择方向。
- 在「更多 → 窗口行为」开启「贴边自动隐藏」后，靠近屏幕工作区边缘松手可保留贴边位置。鼠标离开后藏入边缘，留下额度侧签。
- 在侧签附近停留先唤回圆环，继续移入圆环再展开。只响应侧签附近，不占用整条屏幕边缘；相邻显示器接缝也能停靠，松手指针所在屏幕决定归属。

侧签采用微弧融合轮廓，没有活动监控及未读消息时缩短并居中，有监控信息时连续扩展。侧签可显示剩余额度或已用额度，未知仍显示「—」。菜单打开、拖动和「保持展开」期间暂停自动隐藏。

### 自定义额度弧线

从浮窗右键菜单或「设置 → 显示与提醒」打开弧线调色，选择单色、随额度变化的双色渐变或默认配色。色轮、HEX、预设与预览集中在一个窗口；点击「应用」保存，取消、Escape 或关闭撤销本次调整。

### 保持展开、置顶和收起

「保持展开」让鼠标移开时面板仍保持可见；「更多 → 窗口行为 → 始终置顶浮窗」控制是否位于其他窗口上方。点击「收起」只收回圆环，不关闭程序，也不停止监控。主动收起后，需要鼠标离开再进入才自动展开。

## 系统托盘：快速查看而不占桌面 {#tray}

| 操作 | 结果 |
| --- | --- |
| 悬停托盘图标 | 显示今日用量、账号余量和异常摘要；移开关闭，不抢焦点。 |
| 单击图标 | 打开可操作的详情卡，可查看用量、预算或监控，复制数字、刷新或进入设置。 |
| 双击图标 | 打开主面板。 |
| 右键图标 | 打开分组功能菜单。 |
| 详情卡中按 Esc、点击外部或关闭详情 | 关闭这张卡，后台继续运行。 |

托盘和浮窗都能进入统一设置。全局外观可跟随系统，或选择浅色、深色，各界面还可单独覆盖。

## 显示方式与退出

| 操作 | 后果 |
| --- | --- |
| 关闭主面板 | 释放主面板及其统计服务；托盘、浮窗与已启用监控继续运行。 |
| 仅系统托盘 / 仅悬浮窗 / 托盘与悬浮窗 | 改变常驻入口，保留当前主面板。 |
| 隐藏浮窗至托盘 | 隐藏浮窗并保留托盘入口。 |
| 退出 Codex 用量 | 退出整个工具，停止本工具的统计与提醒；不会结束 Codex 中的任务。 |

Tab / Shift+Tab 可遍历浮窗操作，Enter / 空格执行，Esc 先关闭菜单再收起，Ctrl+Space 切换保持展开。主面板可用 Ctrl+R 刷新、Ctrl+E 导出、Ctrl+, 打开设置、Ctrl+Q 退出。
