# v1.6.0 验证范围

这是公开的验证摘要，未包含个人用量明细、账号信息、任务记录或原始实验日志。验证环境为 Apple Silicon / macOS 26.5；运行组件为 CPython 3.12.14。

## 自动化与发行检查

发布前在整理后的源码目录运行 `python3 test.py`。测试涵盖 Token 解析与去重、磁盘索引、刷新合并与信号退出、额度解析、图表悬停、鼠标交互、浮窗独立筛选、主题切换、菜单栏定位、主面板进程隔离、设置同步、可选 Stop hook，以及运行组件下载与发行包防误打包。

整理后的完整测试：**160 项，158 项通过，2 项按平台跳过**，耗时 40.909 秒。另从空临时目录实际下载两种架构的固定运行组件，大小和 SHA-256 均匹配清单；下载验证后删除临时缓存。

Apple Silicon 与 Intel 两种架构均重新编译并通过嵌套 App 签名校验。在 Apple Silicon 上，真实签名后的宿主及主面板 bundle 分别使用空临时目录执行 `--check-runtime`，均成功完成偏好初始化、离线解压及 Python/SSL/SQLite 导入，未启动 GUI 或读取个人聊天记录。

界面测试包含抽取真实方法后编译执行的测试和离屏 AppKit 测试，不等同于所有操作系统上的端到端测试。两个仅适用于 Windows 的解析分支测试会在 macOS 跳过。

## 本机交互验收

在本次发布整理之前，同一套有效界面和后端源码已完成本机安装与交互验收：

- 菜单栏单击展开、点击外部关闭、双击打开主面板；菜单位于真实菜单栏下方。
- 圆形浮窗悬停展开、移开收起；左键、右键、Control-click、拖动和选择菜单按各自逻辑处理。
- 浮窗的时间、模型、任务可独立选择；主面板范围保持独立。
- 深浅主题原窗口切换，连续切换不会重建浮窗；收起时不持续绘制动画。
- 主面板柱状图悬停显示日期、输入、输出和合计，移开消失。
- 打开、关闭、隐藏主面板及显示/隐藏浮窗，不再连带重启常驻 GUI 或移除菜单栏图标。
- 环宽已调整为 5 点；合成离屏图覆盖两种主题、0/15/50/100%/未知额度及长数字边界。

源码整理移除了废弃控制器与旧测试，未改变以上有效产品逻辑。可重复的本机脚本和合成图片随源码提供，原始个人实验文件不公开分发。

## 内存观察

以下是本次开发期间的 **physical footprint** 采样，单位 MiB，并非 `ps` 的 RSS。自动刷新关闭；额度查询仍可能短时启动独立进程。结果依赖图形缓存、交互历史、日志规模及系统环境。

| 独立主面板版本的场景 | 采样时长 | 无辅助进程时常驻 GUI 中位数 | 采样进程合计峰值 |
| --- | ---: | ---: | ---: |
| 冷启动、收起浮窗 | 20.04 秒 | 13.36 | 13.46¹ |
| 两次主面板开关并操作浮窗后、收起浮窗 | 70.06 秒 | 24.83 | 84.97 |
| 随后切换到菜单栏 | 70.09 秒 | 25.81 | 85.79 |

¹ 冷启动这次采样未捕获额度辅助进程，不能据此推断查询峰值。后两组均有 97.5% 的样本未见辅助进程。所有峰值均为离散采样中的最高值，不保证捕获全部瞬时峰值。

稳定单 GUI 候选方案在两次主面板开关后，收起浮窗约 54.85 MiB；独立主面板方案的对应观察为 24.83 MiB，减少约 30.02 MiB（54.7%）。这是实际使用过程的版本观察，存在日志增长及交互顺序差异，并非严格受控实验，也不能解释为更换语言的单独收益。冷启动两方案接近：13.63 与 13.36 MiB。

另一次离屏主题压力测试执行两组各 250 次往返切换，最终约 17.53 MiB、采样峰值约 27.71 MiB，空闲不继续绘制。它只覆盖有限次数的绘制组件测试，不能证明完整应用永久无内存增长。

因此保留稳定常驻 GUI + 按需独立主面板的设计；菜单栏/浮窗没有闲置常驻 Python。系统图形和字体缓存仍有成本，不能保证任意机器、任意交互后都低于 10 MB。
