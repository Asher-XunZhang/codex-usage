# macOS 使用指南

本页对应 **macOS v1.0.2**。主面板、菜单栏与浮窗使用原生 AppKit，包含用量统计、预算提醒与任务监控。

## 首次使用

按[安装指南](./installation.md#macos)选择芯片。首次建立本机日志索引可能需要等待；账号额度需要本机 Codex 已登录。默认读取 `~/.codex`，也可选择其他来源目录。应用不把 Token 总数当作订阅余量或账单。

## 主面板：用量、预算与监控

页面间切换保留窗口和编辑状态。用量支持时间、模型、任务筛选、每日图表悬停、搜索、排序与 CSV 导出。主面板和浮窗的筛选分别保存；它们不改变预算范围或已选择的监控任务。

### 预算与提醒 {#budgets}

进入「预算与提醒」，选择 Token、估算金额或官方余量下限，设置周期、时区、范围和提醒阈值。估算金额使用自填单价；缺少价格会显示诊断，不按免费计算。官方额度按实际可用窗口选择，失效后需要重新选择。

保存失败保留草稿；提醒可暂停，也可选择在浮窗查看预算。预算不会停止 Codex、限制请求或兑换重置卡。[预算详情](https://github.com/Asher-XunZhang/codex-usage/blob/main/docs/macos/BUDGETS.md)

### 任务监控 {#monitoring}

在「任务监控」选择正在运行的任务，设置本轮或持续监控。使用明确轮次事件判断结束，不用一段时间没有日志来猜测完成。

- 圆环、侧签和菜单栏显示监控摘要，未读消息独立于额度百分比。
- 取消监控只停止本工具的提醒，不停止 Codex 任务。
- 清理结束项、清理历史和标为已读分别管理；打开历史不自动标读。
- 关闭主面板后，常驻宿主继续监控；新消息不强制展开浮窗或抢走焦点。
- 系统通知需获得权限，也可只保留应用内标记。通知显示、正文点击与冷启动跳转的验证范围分别记录。

[监控与通知说明](https://github.com/Asher-XunZhang/codex-usage/blob/main/docs/macos/TASK-MONITOR.md)

## 菜单栏与统一设置

菜单栏可查看用量、额度、预算和监控摘要，打开详情或命令菜单。应用菜单、菜单栏与浮窗均可进入设置；外观支持跟随系统、浅色或深色，各界面可单独覆盖。仅保留菜单栏时也能调整设置。

## 圆环、展开面板与贴边侧签 {#floating}

圆环连续变为展开面板，收起沿原路径返回；动画中也可反向。详情可切换用量、预算和监控，底部保留「打开主面板」与「收起」。

| 操作 | 结果 |
| --- | --- |
| 悬停圆环 | 短暂确认后展开详情 |
| 在可见区域按住并移动，包括按钮和数据区 | 达到拖动阈值后移动整个浮窗，取消原按钮点击 |
| 展开状态下松手 | 保持展开；下一次展开重新按可用空间选择方向 |
| 点击「收起」 | 收回圆环；静止鼠标与收起按钮重叠也不会立即重开 |
| 鼠标移出 | 未保持展开、无菜单或键盘交互保护时自动收起 |
| 靠近屏幕可用区边缘松手 | 贴合该边缘，移出并收起后延迟隐藏成侧签 |
| 在两屏接缝附近松手 | 同样可贴合隐藏；侧签留在松手指针所在屏幕内 |
| 持续按住跨过接缝 | 自由跨屏，不在拖动途中吸住 |
| 悬停侧签 | 先恢复圆环，继续真实移入才展开详情 |
| Esc | 先关闭菜单，再收起详情 |

「保持展开」控制移出后是否继续显示，与「置顶」独立。菜单和拖动期间暂停隐藏；关闭自动隐藏后保留可见圆环。系统开启「减少动态效果」时减少动画，保留防误触等待。

## 额度弧线配色

额度弧随剩余额度由绿经黄、橙变红，未知显示「—」。百分比表示账号额度或所选预算，不表示任务完成进度；监控小标记单独表达任务状态。[统计口径](./metrics-and-privacy.md)

## 关闭、隐藏和退出

关闭主面板释放该窗口及统计服务，菜单栏、浮窗、预算和任务监控继续运行。切换常驻方式保留正在编辑的主面板；隐藏浮窗保留可找回入口。只有「退出 Codex 用量」才结束整个工具。
