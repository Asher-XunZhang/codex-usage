# 统计口径与隐私

## Token、额度和费用

| 数据 | 含义 | 不能据此推算 |
| --- | --- | --- |
| 本机 Token 统计 | Codex 已写入本机日志的记账，按时间、模型、任务聚合 | 尚未记录的消耗、未收集到的其他设备记录 |
| 缓存输入 | 输入 Token 中已标记为缓存的部分 | 不能在输入总量上再次相加 |
| 输出 | 包含记账中的推理输出 | 不能再加一次推理 Token |
| 账号额度 | 通过本机 Codex 的只读接口查询的账号状态 | 不能按本机 Token 固定比例换算 |
| 账单 | 本工具不计算 | 不能把 Token 总数当作费用 |

基本关系为：**输入 = 缓存输入 + 非缓存输入；总数 = 输入 + 输出**。统计展示与本机日志的覆盖范围有关；不能核实的内容会保留未知、缺失或部分覆盖提示。

## 为什么刷新后数字可能没变

手动刷新会请求增量扫描，但应用只能读取已经落盘的记录。正在进行的任务如果尚未写入新的记账，刷新也无法提前获得其最终用量。

Token 扫描和账号额度查询是两个流程。自动刷新可关闭，或设置为 1/2/5/10/30/60 秒及自定义 1–3600 秒；账号额度另按约 60 秒只读查询。调快 Token 刷新间隔不等于额度服务立即产生新数据。

未知额度显示「—」，旧快照会标记状态。未知值不能当作 0，也不能当作额度已用尽。主面板可展示重置卡数量，程序没有兑换入口。

## 数据保存在哪里

| 路径或偏好域 | 用途 |
| --- | --- |
| `~/.codex`（默认） | Codex 本机记录来源；也可在 App 菜单中选择其他目录 |
| `~/Library/Application Support/CodexUsageDashboard/` | 聚合索引、运行组件和工具日志 |
| `local.codex-usage.desktop` | 主面板、菜单栏、浮窗共享的应用偏好域 |

`~/.codex` 属于 Codex 本身，可能包含账号凭据与聊天记录。不要为重装这个用量工具而删除它，也不要将它打包发送给他人。

## 数据是否会上传

工具不上传聊天内容或用量统计。主面板统计服务仅监听本机 loopback；账号额度查询使用本机 Codex 的只读接口，过程中 Codex 自身可能与官方服务通信。因此，“本机统计”不代表所有账号额度查询都完全离线。

公开发行包包含程序、运行组件、文档与许可证，不携带发布者的账号、历史用量、聊天或本机偏好。安装助手也不修改这些数据；App 正常启动后会维护自身的运行组件与索引。

## 反馈时可以提供什么

优先提供系统版本、芯片、App 版本、安装方式、复现步骤和经过检查的错误信息。截图中的任务名、路径或账号信息可先遮挡。不要上传 `auth.json`、认证令牌、整个 `~/.codex` 或整个支持目录。
