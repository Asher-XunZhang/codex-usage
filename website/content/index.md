## 管理使用节奏

两端可设置 Token 预算、按自填价格估算金额，或在官方余量降至下限时提醒。预算只提醒，不限制 Codex 执行。

## 关注任务结束

两端可选择本轮或每轮提醒。关闭主面板后继续监控，在圆环、贴边侧签和托盘保留静态状态标识。

[Windows 监控 →](./windows-guide.md#monitoring) · [macOS 监控 →](./user-guide.md#monitoring)

## 适合当前工作的查看方式

| 你在做什么 | Windows v1.0.2 | macOS v1.0.2 |
| --- | --- | --- |
| 复盘用量 | 主面板的趋势、筛选与明细 | 主面板的趋势、筛选与明细 |
| 专心工作，偶尔看一眼 | 系统托盘悬停摘要、单击详情卡 | 屏幕顶部菜单栏 |
| 在桌面保留额度 | 圆环、四边隐藏侧签、可拖动展开面板 | 圆环、四边侧签、连续形变与整窗拖动 |
| 等待任务完成 | 应用内标记与可选 Windows 系统通知 | 应用内标记与可选 macOS 系统通知 |

Windows 浮窗的用量、预算页保留电池式额度摘要；监控页显示任务状态与独立未读入口。新消息不会自动展开、移动窗口或切走正在查看的页面。[查看浮窗操作 →](./windows-guide.md#floating)
