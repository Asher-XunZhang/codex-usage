# macOS 任务监控

此功能随 macOS v1.0.2 发布。主面板选择“任务监控 → 选择任务”，按名称或项目搜索后多选，设置“仅所选本轮”或“持续每一轮”。提交时重新核对轮次；尚不能可靠确认的任务不允许订阅。

监控与 Token 筛选独立，只读取本机日志。明确的开始、结束和中断事件决定状态；没有根据日志安静猜测完成，也不推测审批等待或执行失败。停止提醒不停止 Codex，不发送消息或代为批准操作。

圆环和贴边侧签保留额度百分比及色阶，底部蓝色监控标记独立显示：执行中为省略号、结束为勾、中断为方块、待确认为问号、等待下一轮为时钟，未读数量另列。常驻关注只决定重点显示，不停止其他订阅。没有监控和未读时恢复普通范围标签；新消息不自动展开浮窗。

浮窗选择“监控”后可查看前三项任务、打开任务详情、停止单项提醒、清除已结束结果和打开提醒设置。任务更多时进入主面板。消息入口有未读时打开“未读”，否则打开“历史”；进入列表不自动标读，打开单条消息或明确标读才改变未读状态。“检查任务”只核对本地来源，有独立进行中及检查时间，不测试系统通知、不发起账号额度查询。

主面板支持单条／全部标读、清理已读历史、清理已结束结果、停止提醒、取消关注和策略切换。暂停任务通知仍继续记录。默认系统通知与应用内标记、无声、历史保留 30 天；未读消息不按普通已读历史静默清除。任务与预算通知共用系统路由，但暂停设置各自独立。

关闭主面板后宿主继续监控；退出应用后停止，重启恢复订阅并核对离线记录。离线完成补入消息，不逐条补弹旧通知。系统横幅、声音和通知中心受 macOS 权限与专注模式控制；当前测试边界见[验收记录](FEATURE-SYNC-VALIDATION.md)。

记录位于应用数据目录的 `desktop/task-monitor.json`。损坏时保留原文件，提供备份并重建入口；此操作不修改 Codex 日志。备份成功后仍须新文件写入成功才算恢复完成；写入失败保留备份和恢复入口，可排除存储问题后重试。问题报告不要附完整监控文件、私人名称或日志正文。

浮窗交互：单击按钮执行动作，按住任意内容移动超过 3 pt 则拖动整个浮窗；拖动松手保留展开，越界时恢复到可用区域。摘要双击可进入文字选择复制；受限尺寸下原生滚动条仍用于滚动。普通展开不会自动开启保持展开，普通鼠标焦点也不会阻止移出收起。只有明确选择保持展开或进入键盘操作时保留详情。主动“收起”或 Esc 清除保持展开与键盘保留；指针实际离开后再进入才恢复普通悬停展开。

### 从系统通知查看消息

点击任务通知会打开本次通知关联的消息范围，可用“返回全部历史”取消限制；打开时不会自动标为已读。“本通知全部标为已读”只修改该通知中的消息。消息已清理或不符合当前搜索时显示空状态，不用其他任务替代。通知中的后台标读／暂停操作等待存储回执后完成。
