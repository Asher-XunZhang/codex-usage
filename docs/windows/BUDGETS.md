# Windows 预算管理

[Windows 使用说明](README.md) · [界面设计](LAYOUT-PROPOSAL.md) · [验证范围](VALIDATION.md)

预算用于观察用量或额度并在接近阈值时提醒，不限制 Codex 执行，也不修改套餐或订阅账单。预算范围与用量页筛选独立。

## 预算类型

| 类型 | 依据与范围 | 注意事项 |
| --- | --- | --- |
| Token 数量 | 本机落盘记录，可选时间、模型和任务 | 支持总 Token、非缓存输入加输出、仅输出；缓存和推理不重复相加 |
| 估算金额 | 本机用量乘以自定义每百万 Token 单价 | 不是订阅账单；缺价或分类不完整时无法确认剩余 |
| 官方余量下限 | 账号实际额度窗口和剩余比例 | 不按模型或任务拆分；未知或过期不当作零 |

金额预算分别填写模型的输入、缓存输入和输出单价，未填写不表示免费。界面列出缺失项，可补齐后重算本期。只有部分用量可估价时显示已知消费下界，不伪造精确剩余。

## 新建与编辑

1. 进入“预算管理”，新建并选择类型、名称和额度。
2. 对 Token 或金额预算选择模型、任务与周期；官方提醒从实际账号窗口中选择。
3. 配置阈值，确认生效时间后保存。

周期支持每日、每周、每月、自定义时段和固定时长，可选择时区及重置时刻。无效日期或选定时区中不存在的时间会提示错误，不能按旧值悄悄保存。

默认 Token / 金额阈值为剩余 20%、10%、0%，可修改。同一监测周期每级只提醒一次；官方下限在监测周期或官方窗口重置后可再次提醒。

草稿按预算分别保留，切换预算不会覆盖另一份未保存内容。“保存”和“取消”固定可见；保存前区分立即生效与下期生效，详情可对照本期和待生效配置。调整本期统计时使用明确的重算入口，不将下期设置当成本期已改变。

## 查看与控制

| 操作 | 后果 |
| --- | --- |
| 在浮窗查看 | 显示浮窗并选中预算，不改变用量页筛选 |
| 暂停提醒 | 继续统计，按时间或当前周期暂停提醒 |
| 恢复提醒 | 恢复提醒，不改变范围和额度 |
| 停用预算 | 停止该规则监测，规则保留，可重新启用 |
| 复制 | 创建可独立编辑的新预算 |
| 删除 | 删除规则和提醒历史，保留用量记录；需要确认 |

浮窗预算页显示余量、周期、范围与提醒状态，顶部电池只表示所选预算剩余比例。暂停与停用分别标记；打开浮窗不强制关闭主面板。

Token 和金额预算使用本地更新节奏，暂停自动更新后可手动刷新。官方额度约每 60 秒更新，也可手动请求；两个来源分别显示时间和错误。

## 数据可信度

- 预算绑定创建时的日志目录，不随用量页筛选改变。切换目录后应回到原目录编辑，或另建规则。
- 缺价、缓存分类缺失、覆盖不足、窗口不存在和额度过期分别提示。未知不当作已用完，也不触发基于伪造数值的精确提醒。
- 提醒状态保存失败时保留错误并暂不发送，防止重启后重复提醒。
- 自定义价格估算不能推断订阅真实收费或可用请求数。

## 保存与恢复

规则和提醒状态位于 `%LOCALAPPDATA%\CodexUsageDashboard\desktop\budgets.json`；草稿位于同目录 `settings.json` 的 `budgetDraft` 内容。`CODEX_USAGE_DESKTOP_BASE` 可指定隔离目录。

文件损坏时暂停监测并保留原文。恢复先备份，再建立可读取配置；旧规则和提醒历史保留在备份中，不自动重新监测，用量记录和草稿不因此删除。保存或关闭失败时保留重试状态，不用强制退出掩盖未保存内容。
