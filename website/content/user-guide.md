# 使用指南

本页介绍 v1.0.1 的主面板、菜单栏和圆形浮窗。三种界面均为 macOS 原生窗口，无需在浏览器中查看。

## 首次使用

先按 [安装指南](./installation.md)安装匹配芯片的发行包。使用过 Codex 后，工具读取这台 Mac 已落盘的本地记账；账号额度需要本机 Codex 已登录。首次建立历史索引可能需要等待。

默认数据目录是 `~/.codex`，也可在应用菜单中选择其他目录。Token 数量来自本地日志，账户剩余额度是另一套只读信息，二者不能相互换算；详见 [统计与隐私](./metrics-and-privacy.md)。

## 主面板：查看历史和精确计数

主面板适合查看历史趋势和定位具体任务：

- 统计范围可选今天、7 天、30 天、90 天或全部时间。
- 按模型、任务筛选，查看输入、输出、缓存和调用次数。
- 将鼠标移到柱状图的柱子上，显示该日期的输入、输出和合计；移开后提示消失。
- 可搜索、排序，并导出 CSV。

主面板与浮窗各自保存筛选条件。例如浮窗选择 30 天时，主面板可以继续保持 7 天。

## 菜单栏：快速查看今日用量

| 操作 | 结果 |
| --- | --- |
| 单击顶部用量图标 | 展开菜单，查看今日 Token 与剩余额度 |
| 点击菜单外部 | 关闭菜单 |
| 双击顶部用量图标 | 打开主面板 |

菜单应显示在菜单栏下方。如果图标、菜单或窗口行为异常，请查阅 [故障排查](./troubleshooting.md)。

| 鼠标操作 | 结果 |
| --- | --- |
| 悬停浮窗 | 立即开始展开详情 |

## 额度弧线配色

[PR #3](https://github.com/Asher-XunZhang/codex-usage/pull/3) 已包含在 v1.0.1。弧线随剩余额度降低，由绿经过黄、橙连续转为红色；整段剩余弧线保持同一种颜色。5% 及以下保持警示红，0% 只保留中性底环和 `0%`，未知额度显示「—」。

弧线对应上方「周余」等标签所指的**账号额度**；下方 Token 数量由独立的时间、模型和任务筛选决定，两者不能互相换算。旧快照保留 `*` 标记，颜色变化不能用来判断数据是否已刷新。

v1.0.0 使用固定绿色弧线；更新到 v1.0.1 后即可使用新配色。具体色值、动画及边界规则见 [额度弧线配色](./architecture.md#额度弧线配色)。

## 刷新：何时会看到新数据

手动刷新会立即请求增量扫描，扫描完成后更新读数。它不会让尚未写入 Codex 日志的消耗提前出现。

自动刷新可以关闭，或选择 1、2、5、10、30、60 秒，也可自定义 1–3600 秒。三种界面共享刷新间隔，但各自的筛选条件独立保存。账号额度另按约 60 秒进行只读查询，不能把统计刷新间隔当作额度查询频率。

未知额度显示「—」，旧快照带标记。主面板可显示重置卡数量，没有兑换入口。

## 关闭窗口与退出应用

| 操作 | 对其他界面的影响 |
| --- | --- |
| 关闭或隐藏主面板 | 菜单栏与浮窗继续运行；主面板及其统计服务退出 |
| 关闭浮窗 | 不影响主面板 |
| `⌘H` | 隐藏并释放主面板 |
| `⌘Q` 或明确选择「退出」 | 退出整个工具 |
| 选择「仅状态栏」或「仅保留胶囊」 | 按所选模式调整其他窗口 |

如果主要关注轻量常驻，可以在查看历史后关闭主面板，保留菜单栏或浮窗。它们没有闲置常驻 Python，但系统字体和图形缓存仍有成本，不能保证占用低于 10 MB。进程设计见 [架构](./architecture.md)，实测边界见 [验证范围](./validation.md)。
