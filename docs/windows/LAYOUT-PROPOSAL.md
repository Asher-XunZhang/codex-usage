# Windows 界面与交互设计

[使用说明](README.md) · [预算管理](BUDGETS.md) · [任务监控](TASK-MONITOR.md) · [验证范围](VALIDATION.md)

界面按数据范围和操作后果分组。主面板承担完整查看与编辑，浮窗提供高频摘要和快捷操作，托盘提供常驻入口。三处共用状态和设置，避免同名操作产生不同结果。

## 页面分组

| 区域 | 内容 | 作用范围 |
| --- | --- | --- |
| 主面板固定导航 | 用量概览、预算管理、任务监控；显示方式、设置 | 切页后仍可访问 |
| 账号摘要 | 周与短周期额度、重置时间、重置卡 | 账号级，不受本地筛选影响 |
| 数据更新区 | 本地和账号的更新时间、错误、刷新和更新设置 | 分别说明数据源，不合并成含义不明的状态 |
| 本地范围区 | 时间、模型、任务、重置筛选 | 指标、趋势和明细共享范围 |
| 明细工具栏 | 分组、搜索、导出 | 搜索只过滤明细；导出明确选择显示行或范围全部行 |
| 预算详情 | 编辑、浮窗查看、周期、范围、依据、待生效修改 | 所选预算，不继承用量页筛选 |
| 预算提醒区 | 阈值、暂停和恢复 | 暂停提醒与停用规则分开 |
| 预算编辑固定底部 | 保存、取消、生效时间、错误摘要 | 编辑区域滚动，主要操作保持可见 |
| 监控页 | 订阅列表、消息记录、常驻关注、提醒设置 | 独立于统计筛选，已读与执行状态分开 |

全局设置包括外观、显示与浮窗、数据与更新、帮助与恢复。主面板、浮窗更多和托盘菜单进入同一份设置；快捷菜单不创建另一套偏好。

## 浮窗三页

顶部保留单个主体轮廓。用量页显示周余与今日 Token，预算页显示当前预算剩余；圆角电池填充只表示对应余量，文字排版不随填充边界裁切。未知显示“—”，上次记录有独立标记。

监控页顶部使用[动态摘要](MONITOR-HEADER-PROPOSAL.md)，不保留上一个用量或预算页的数据。监控符号、未读数和额度含义彼此独立。

摘要下方左侧是用量、预算、监控导航，右侧是保持展开与更多。底部保留打开主面板与收起；置顶留在“更多 → 窗口行为”，不与保持展开混为一个开关。

用量内容显示范围、可收拢的模型/任务筛选及拆分。预算内容显示所选预算、周期、范围和提醒状态。监控内容显示重点任务、查看、取消、清除已结束结果与检查反馈；完整列表进入主面板，避免卡片增长挤掉底部按钮。

## 连续形变与手势

展开轮廓为 336×410 DIP，主面板最小为 760×640 DIP。窄主面板换行，表格独立横向滚动；不靠持续缩小文字挤进窗口。

圆环与面板使用同一轮廓形变，额度或主状态只绘制一次；详情在可容纳时出现，反向收起沿同一路径进行。动画中未显示完整的操作不能提前点击。透明原生窗口预留形变范围，透明区域不作为命中区；普通展开不持续调整 HWND 尺寸。

圆环悬停等待 140 ms，为立即抓取留出机会。按下取消悬停等待；未完整展开时可抓可见区域并继续圆环拖动。完整面板内任意位置可拖动，跨越 3 DIP 阈值后不可再变成点击，即使拖回起点也一样。松手、丢失捕获、隐藏和显示布局变化必须结束对应手势；旧保存回调不影响下一次操作。

按住时面板自由跟随；松手内部位置保留，越界时以 160 ms 无过冲过渡回到可见范围。外壳、内容与命中区一同回位；再次按下可接管。贴边意图先于面板回位确定，圆环锚点不被推离边缘。每次重新展开按当前空间选择方向，不持久锁定上次方向。

开启贴边隐藏后，在工作区边缘 16 DIP 范围内可吸附；相邻屏幕真正连接的部分不隐藏，错位屏幕露出的外边段仍有效。左/右侧签为 28×72 DIP，上/下侧签为 76×28 DIP。局部唤醒范围仅在侧签周围，不覆盖整条屏幕边缘。

| 动作 | 等待 | 视觉过渡 |
| --- | --- | --- |
| 圆环悬停展开 | 140 ms | 280 ms |
| 离开面板收起 | 90 ms 确认 | 220 ms |
| 贴边圆环隐藏 | 550 ms | 220 ms |
| 侧签附近唤回圆环 | 120 ms | 160 ms |
| 越界释放后回位 | 无额外等待 | 160 ms |

这些是完整过渡目标值，中途反向从当前状态继续。系统关闭动画后直接呈现终态，但保留防误触的停留与离开等待。旧圆环与面板间过渡区只短暂保留展开，继续离开时即使没有新的窗口鼠标事件也必须收起。

## 输入与错误

鼠标悬停、选中和键盘焦点分别表达。被动窗口焦点返回不等于用户开始键盘导航；Tab、Enter、空格和读屏仍有可见且逐项的操作提示。菜单关闭后恢复焦点必须检查操作代次，不能覆盖新的拖动或键盘意图。

异常通过明确入口呈现完整说明，不依赖覆盖整个浮窗的文字提示。读取失败、设置未保存、预算缺价和来源不可用分别说明影响与恢复动作。详细审查原则见[交互审查](UX-REVIEW.md)。
