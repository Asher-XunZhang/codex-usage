## 本次反馈引出的额外修正

此前 C 项只覆盖了非控件区域，遗漏 Windows 的全区域拖动；展开拖动松手被强制收起，且丢失鼠标最终移动。现在统一手势判定，并按面板边缘检测停靠，保留这次展开的方向和抓取位置，下一次展开重新选择方向。

主动收起和键盘焦点保留存在优先级冲突；旧圆环热点也可能覆盖展开后的按钮。主动收起会清除键盘保留，实际指针移动取消旧热点。形变产生的退出事件不能解除主动收起保护，须同时满足真实位移与离开可见轮廓。邻近按钮及额度摘要的光晕遮罩已移除，改为背景 → 连续光晕 → 文字的绘制顺序。

监控浮窗原本只有汇总和主窗口入口，缺少 Windows 的任务快捷操作；现已补入预览、查看、停止、清理、消息与设置。监控检查使用自己的进行中状态，避免与 Token 刷新相互禁用。

## 仍需区分的边界

- Intel 为交叉编译；本机不能替代 Intel、Windows、真实外接多屏及拔屏／Spaces 验收。
- 系统通知 API 和路由测试不代表横幅已出现或冷启动点击已完成。
- 原生合成鼠标／像素测试不等于真实桌面操作；对应证据分开报告。
- 可靠审批等待／失败判定、自动模型价格、官方期间消耗预算并非 Windows 当前已完成能力；本轮不伪造这些状态。
- 新功能有内存开销，没有整机耗电收益测量，不能宣称零轮询或更省电。
