| --- | --- | --- |

## 维护约定

- 平台专属文档与截图分别放入该平台目录；截图放在其 `images/` 下，需要保留版本证据时再建版本子目录。
- 跨平台比较及公共工具说明放入 `common/`；一端的实现细节不因使用通用标题就视为两端约定。
- 新增或移动文档时，同步相对链接、图片引用、相关构建与打包入口。固定发行版本或提交的外部链接保留历史路径。
- 方案、已实现行为与验收证据分别标明状态和适用版本，不把历史截图或测试结果当作当前版本保证。

所有文档中的命令，如无特别说明，均在仓库根目录执行。此目录仅保留导航，具体说明归入对应分类。
