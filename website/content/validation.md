# 验证与兼容性

不同检查证明不同范围：架构和签名完整性通过，不等于 Apple 公证；Rosetta 执行通过，不等于所有实体 Intel Mac 通过。当前发行版为 v1.0.1。下方保留 v1.0.0 App、安装助手和配色开发阶段的历史验证记录；各项结果只适用于注明的版本与环境。v1.0.1 打包验证见[发行验证文档](https://github.com/Asher-XunZhang/codex-usage/blob/v1.0.1/docs/VALIDATION.md)。

## v1.0.0 正式发行记录

来源：[v1.0.0 基线 `53c9cf4` 的完整验证文档](https://github.com/Asher-XunZhang/codex-usage/blob/53c9cf4fcfc3c549be61dbfe77facb2af1b87ca8/docs/VALIDATION.md)。环境为 Apple Silicon/macOS 26.5，运行组件 CPython 3.12.14。

- 完整测试 160 项：158 项通过，2 项按平台跳过，耗时 40.909 秒。
- 两种架构发行包均检查架构、嵌套签名、归档内容及固定运行组件摘要。
- 在空临时目录检查正式 App 的宿主和嵌套主面板离线组件初始化，未打开 GUI 或读取个人聊天记录。
- 本机已验收菜单栏定位与关闭、圆形浮窗鼠标行为、独立筛选、主题切换、图表悬停及独立窗口生命周期。

测试中包含抽取方法后编译执行与离屏 AppKit 检查；这些不能替代所有系统上的完整端到端操作。

## Intel 启动反馈与安装助手验证

一个实体 Intel/macOS 15.7.9 用户报告：原始 v1.0.0 的 x86_64 架构、执行权限、签名完整性均通过；隔离属性处理后可以启动。该反馈只证明这个案例的启动恢复，未覆盖任意 Intel 机型与全部功能。

[PR #1](https://github.com/Asher-XunZhang/codex-usage/pull/1) 已于 2026-09-11 合并到 `main`，合并提交为 [`d6a9407`](https://github.com/Asher-XunZhang/codex-usage/tree/d6a9407a86325eaf210e7d69f58a63ba4f5eab8e)。安装脚本与原验证提交 [`99c881d`](https://github.com/Asher-XunZhang/codex-usage/tree/99c881de9890bc22cd287aaec069ec881152deb6) 的内容相同；以下是该验证提交完成的检查，并非合并后重新进行了一轮实机验收：

- 新增 19 项安装器行为测试全通过；该分支完整测试 179 项，177 项通过，2 项 Windows 专用测试跳过，53.873 秒。
- Apple Silicon/macOS 26.5 上，实际从 GitHub 在线下载安装 Apple Silicon 包；模拟 Intel 硬件识别后，使用原始 Intel ZIP 离线安装。
- 两种架构安装后的宿主和嵌套主面板分别运行 `--check-runtime`，四次均退出 0；Python、SSL、SQLite 导入通过，Intel 执行使用 Rosetta。
- 实际 Rosetta 终端能正确选择 Apple Silicon 安装包；隔离处理仅影响临时安装副本，已有文件不被覆盖。

这套安装器还没有完成实体 Intel/macOS 15.7.9 的完整安装与交互验收。它减少安装步骤，没有为现有 App 增加 Apple 公证。

## v1.0.0 历史内存观察

以下为正式发行文档记录的 **physical footprint**，单位 MiB；不是 `ps` 的 RSS。自动刷新关闭，额度查询仍可能临时启动进程。

| 场景 | 时长 | 无辅助进程时宿主中位数 | 观察到的相关进程合计峰值 |
| --- | ---: | ---: | ---: |
| 冷启动、收起浮窗 | 20.04 秒 | 13.36 | 13.46¹ |
| 两次主面板开关并操作浮窗后，收起 | 70.06 秒 | 24.83 | 84.97 |
| 随后切换到菜单栏 | 70.09 秒 | 25.81 | 85.79 |

¹ 冷启动采样未捕获额度辅助进程，不能据此推断查询峰值。后两组 97.5% 的样本没有辅助进程。采样可能漏掉瞬时进程和峰值；结果依赖日志规模、交互历史及系统缓存。

开发期一次单 GUI 与独立主面板版本观察得到 54.85 MiB 和 24.83 MiB，但它不是固定数据集上的严格受控对照，不能解释为编程语言变化的单独收益。有限离屏主题压力测试也不能证明完整应用长期没有内存增长。完整过程及边界保留在源文档中。
